## Scope in / out

IN: semantic design tokens; 4 immutable presets (Dark, Light, Claude Code-inspired, Codex-inspired) + 5th «Своя» with expandable editor (clone/validate/contrast/preview/Save/Apply/Cancel/Reset); independent per-area typography (8 areas, theme switches never reset them); App Shell (LeftSidebar 260/48, CenterWorkspace, RightSidebar 340 hidden default, StatusBar 28px, empty central TerminalSlot); real projects/sessions/chat/resources/modules/settings adapted to the shell; versioned Desktop-only persisted appearance/layout settings (atomic, fail-safe defaults); accessibility (keyboard, IME, focus return, tooltips, reduced motion, responsive 1440×900/1280×800/1024×768).

OUT (UI-B / later): real Windows CPU/RAM polling, WSL PTY terminal (slot only), Dashboard #17, NSIS, merge, installs into the working profile, changes to PR #19, font redistribution, new Pi/Bridge implementations.

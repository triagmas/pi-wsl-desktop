## 2. Состояние `app` — целостный главный экран

`http://localhost:5199/?state=app` (picker → `app`), `?bare=1` для снимков,
`&variant=a|b` — геометрические альтернативы (каждая ЦЕЛИКОМ, только CSS-переменные).

Композиция: TitleBar(wordmark) | сайдбар «Открыть проект» + поиск + «Новый диалог»
+ дерево проектов + навигация 4 | центр: breadcrumb + чат (сводка → ответ →
«Изменены 2 файла» → «Открыть изменения») + композер + терминал | панель
«Изменения» (scope Ход/Сессия/Git, ветка, файлы, unified diff 42–53) |
статус-бар (⑂ main · Pi готов · Ubuntu/WSL · Windows/CPU/RAM · тумблер терминала).

Управление (локальный state, `setState` только в обработчиках):
тумблер терминала (`aria-pressed`), кнопка панели (`aria-expanded`).

## Известные расхождения (решение за владельцем, D2)

1. **ref5: чат-контент не влезает** — actions «Скопировать/Попробовать ещё раз» и 3-й bullet
   перекрыты композером. Причина: вертикальный стек ниже md (пузырь+9, md+9, шаги+6,
   заголовок/буллеты-гэпы) суммарно ~+90px против эталона при меньшей msgs-области
   (терминал-состояние). В ref1/ref4 тот же стек в пределах ±4px, поэтому правка
   общими гэпами ломает их — нужен отдельный профиль плотности для terminal-состояния
   либо владелец принимает факт.
2. **Ширина/переносы md-колонки**: REF переносит «…диалоги по названию / и содержимому.»,
   NEW — «…диалоги по / названию и содержимому.» (колонка/кегль текста ответа уже у REF).
3. **wordmark titlebar**: REF шире на 11px (трекинг/кегль), цвет совпадает.
4. **status-left ширина −21**: внутренние интервалы блока «Pi подключён | Ubuntu · WSL».
5. **rail «π» +5 вниз**: вертикальная раскладка верхней группы иконок rail.
6. **Цвета, измеренные по эталонам (токены vs Reference)** — зафиксированы color-mix/var:
   status-dot `#60C149` (измеренный 96,193,73), status-term accent α53% (75,95,74),
   step-check dark = success α70% (97,136,103), step-check light = accent (102,126,105),
   user-bubble в dark-эталонах = surface (41,44,39), light newchat = light accent (102,126,105).
   Токен-дельты **не** правятся сменой палитры ( Issue §1 палитры иммутабельны).
7. **Производные кегли** измерены по эталонам и задокументированы в шапке
   `src/renderer/design/typography.css` (hint 12.5px, heading «Готово» 22px, step pitch 51.5px и т.д.).

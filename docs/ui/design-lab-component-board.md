# Design Lab — страница «Компоненты» (board)

**Контекст**: Issue #21, Design Lab D1 (ветка `design-lab-d1`). По запросу владельца —
страница со **всеми элементами дизайна** по эталону `Reference/component-board.png`
(`BOARD-PROMPT.md`), где **переключатели работают**: поля выбираются/заполняются,
цвета выбираются, шрифты выбираются и т.д. + отчёт (этот файл).

**Статус**: реализовано и проверено. **Раунд 3 (ячейки 10–36 из Component Library v5) завершён — STOP перед visual ACCEPT владельцем.**

## 1. Как открыть

```bash
npm run design                       # dev-server http://localhost:5199
# → http://localhost:5199/?state=board&bare=1
```

Picker Design Lab (низ справа) содержит пункт `board`. `?bare=1` скрывает picker
(для чистых скриншотов). Страница — **fixture/представление**: без Electron, Pi,
WSL Bridge, IPC и user `~/.pi`.

## 3. Глобальные контролы в шапке страницы

| Контрол | Что делает | Механизм |
|---|---|---|
| **Тема**: Тёмная / Светлая / Claude / Codex | полная смена палитры всей страницы | `applyTheme(root, THEME_PRESETS[id].tokens)` — иммутабельные токены Issue §1 |
| **Своя тема** + слайдер «Акцент» (0–360°) | интерактивный предпросмотр: акцент/кнопки/линки/фокус/выделение перекрашиваются в реальном времени | производные токены от DARK, hue → `hsl()`; свитч на пресет **всегда** сбрасывает custom (единый эффект) |
| **Шрифт**: Segoe UI / System UI / Georgia / Cascadia Mono | семейство всей страницы (и всех 9 ячеек) | `applyTypography` → `--pw-font-ui-family`; `.dl-board` наследует токен, а не фиксированный стек |
| **Кегль %** (70–150) и **Насыщенность** (300–700) | масштаб/вес выбранной зоны | `--pw-font-ui-size/weight`; типография остальных зон не трогается |
| **Зона** (8 зон: Интерфейс, Боковая панель, Поле ввода, Ответы Pi, Код, Вывод инструментов, Терминал, Статус-бар) | куда применяются кегль/вес/семейство | `typographyCssVarNames(area)` |
| **AA-бейдж** (правый верх) | контраст `accentText on accent` для текущей темы | `meetsAA(hexColor(...))`; для «Своей темы» при hue≈210 показывает **AA ✗** — честный результат, не прячется |

Все значения **реально доходят до DOM** (проверено прямым замером `getComputedStyle`).
